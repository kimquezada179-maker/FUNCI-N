#### Objetivo del programa 
Este programa básico permite verificar si una persona es mayor de edad.
- Se definió la función `def verificar_edad(edad, mayor_edad)` con sus dos parámetros.
- Contiene un cálculo interno que verifica si la edad es mayor o igual a la variable `mayor_edad`: `resultado_edad = edad >= mayor_edad`.
- Retorna el valor con `return resultado_edad`.
- Se llama la función dentro del bloque `if __name__ == "__main__":`.
- Por último, muestra en pantalla el resultado en consola (`True` o `False`).
